# Plan de Carrière — Mbaihornom Willifred

Site web personnel présentant mon plan de carrière en **Génie Logiciel & Développement Systèmes**, avec un suivi des opportunités de formation, bourses, stages et plateformes freelance accessibles depuis le Tchad.

## 🎯 Objectif

Passer de Licence 3 Fondamentale en Code à **Ingénieur Logiciel professionnel** via un plan structuré en 4 étapes, en exploitant les ressources gratuites et bourses internationales.

## 🎨 Structure

Toutes les pages (sauf la vitrine) utilisent la même mise en page de dashboard :
- `dashboard.css` : thème clair vert/citron et composants communs
- `app.js` : barre latérale, barre du haut et menu mobile, générés sur chaque page

Les icônes viennent de [Lucide](https://lucide.dev), chargé depuis unpkg.

## 🚀 Déploiement

Hébergé sur GitHub Pages. Site statique en HTML/CSS/JS, sans étape de build.
